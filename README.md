# MEP Building Project

This project documents the planning and execution of MEP systems for a new commercial building.

## Scope of Work
- Fire Alarm System
- Fire Fighting & Sprinkler System
- HVAC System
- Electrical & Lighting
- Biometric Access Control
- LAN & Low Current Systems

## Responsibilities
- Site execution and coordination
- Installation and testing
- Compliance with NBC and NFPA standards

## Tools & Standards
- AutoCAD
- NBC, NFPA, IS Codes
